## 🚀 Cara Menjalankan

1. **Buka Aplikasi Interaktif:**
   * Cukup klik dua kali (atau buka) file `.html` mana saja menggunakan browser modern (Google Chrome, Microsoft Edge, Safari, Firefox).
   * Seluruh aplikasi bersifat *standalone* tanpa memerlukan web server lokal (semua styling dan script sudah termuat rapi).

2. **Mencetak Lembar Kerja:**
   * Klik tombol **"🖨️ Cetak Lembar Kerja A4"** yang tersedia di bagian atas setiap aplikasi web, atau buka langsung file `.pdf` yang sudah disiapkan untuk dicetak pas ukuran A4.
